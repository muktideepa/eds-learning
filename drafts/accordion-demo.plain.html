What is Edge Delivery Services?

Edge Delivery Services (EDS) is Adobe's high-performance web delivery layer built on top of the Helix/Franklin architecture. It serves content directly from the CDN edge, achieving near-instant page loads and perfect Lighthouse scores.

How are blocks created?

Each block lives in its own folder under blocks/ with a matching .js and .css file. The JS exports a default decorate(block) function that transforms the authored HTML into the final rendered structure.

Do I need a build step?

No. EDS uses plain ES6+ modules loaded natively by the browser. There is no bundler, no transpiler, and no build step — just vanilla JavaScript, CSS, and HTML.

Where does content come from?

Content is authored in Google Docs or Microsoft Word documents, then synced to the AEM backend via AEM Sidekick. The backend converts documents to clean semantic HTML which the blocks then decorate.
